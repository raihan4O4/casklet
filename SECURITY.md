# Security policy

Please do not disclose suspected vulnerabilities in a public issue. Until a private project reporting address is established, contact the repository owner privately and include affected revision, impact, reproduction steps, and whether user data may be at risk.

Casklet is pre-release software and must not be trusted with important data. Its highest security objective is preserving unrelated data. See `docs/security/threat-model-v0.1.md` for the current model and release gates.

Never include secrets, private file contents, complete personal paths, signed URLs, or unredacted diagnostics in a report.
