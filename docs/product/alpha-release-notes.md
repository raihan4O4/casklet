# Casklet 0.1.0-alpha.1

Windows 11 x64 · local/limited testing candidate · unsigned

## Available

- Casks, descriptions, categories, Archive/Restore, and confirmed empty-Cask removal.
- Reference and explicit management at an existing location; compact expandable resource details.
- Cleanup creation, review, exact approval, and journaled execution in the Alpha profile.
- Recycle Bin for eligible owned files/directories; permanent deletion only for eligible internal files with extra confirmation.
- Durable cleanup history and interrupted-run inspection/preserved closure.
- Select and Install workflow with automatic verified new MSI and supported registered EXE ownership, application uninstall preview/approval/execution, and durable uncertain-result recovery.
- Modal Cask removal, immediate library updates, completed Activity display clearing, and safe empty-storage retirement with audit metadata retained separately.
- Portable ZIP workflows, Windows application association, WinGet install, cautious MSI/EXE artifact workflows, manifests/exports, and database metadata backup.

## Before testing

Back up resource data and database metadata. Use dedicated test files first. Referencing never grants deletion ownership. Shared, changed, missing, ambiguous, and unverified items are kept. A cleanup plan leaves the Cask until its remaining dependencies are resolved and removal is confirmed. Inspect Advanced details and Activity if work is interrupted; preservation closure does not automatically restore quarantined data.

## Limitations

- WinGet uninstall is disabled pending independent provider/elevation review; uninstall externally and review associations.
- EXE ownership requires one verified new Windows registration and a supported safe uninstall mechanism. Ambiguous/unsupported installers and legacy informational associations are preserved without automatic uninstall authority. References detach without uninstall; owned application queues verify each result and retain failed ownership for review/retry.
- Copy/Move user intake remains temporarily disabled; legacy resources/recovery remain supported.
- Permanent deletion is unavailable for folders and files managed at their current location.
- No sandbox, arbitrary installer tracing, automatic update, cloud sync, or Linux/macOS release.
- Independent destructive review, clean-machine install/upgrade/Settings-uninstall, real UAC/provider matrix, screen-reader/high-DPI checks, and publisher signing are not complete.
- Recycle Bin availability/recovery varies by volume and Windows configuration; a failed handoff is retained as uncertain rather than retried automatically.
- Local candidates can contain uncommitted source, explicitly identified by provenance and source checksums. Do not treat them as a published release.

Report steps, build version, and redacted diagnostics when filing an issue. Do not share personal database files or filesystem paths without reviewing their contents.
